# Wandr — Frontend

React 19 + TypeScript + Vite. Per la documentazione completa dell'app (backend incluso, modello dati, endpoint, setup) vedi il [README principale](../README.md).

## Comandi

```bash
npm install
npm run dev       # dev server su http://localhost:5173
npm run build     # type-check + build di produzione
npm run lint
npm run preview
```

Richiede il backend attivo su `http://localhost:5174` (vedi [README principale](../README.md#avvio-del-backend)).
